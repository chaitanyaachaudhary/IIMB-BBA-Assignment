# Chaitanyaa Portfolio

A responsive personal portfolio built with **HTML5 and CSS3 only**.

## Files
- `index.html` — semantic page content and structure.
- `style.css` — all visual design, layout, responsive styling, hover effects, transitions, and CSS animations.

## Run locally
Open `index.html` in a web browser. No installation, build step, JavaScript, or framework is required.

## Publish with GitHub Pages
Upload both `index.html` and `style.css` to the same repository folder. In GitHub, open **Settings → Pages**, choose the deployment branch and folder, and save.

**Important:** HTML defines the page's content and structure; CSS controls its appearance. The site intentionally still contains HTML, but its design and responsive presentation are handled in the separate, expanded `style.css` file. GitHub's language percentage is based on the files included in the repository, not on how much CSS visually affects the page.
